Setup, planning, and goal

Setup
To setup the codebase and save version history, we created a github repository and periodically comitted our work there.

Planning
To plan, a project was created in github and issues would be added there to track progress and clearly show what needed to be worked on. Each issue would be split into the 5 default categories: backlog, ready, in progress, in review, and done.

What is the end goal?
The foremost goal of this project is to strengthen our knowledge and curiosity in physics while also using another skill we love, programming, to accomplish that. Additionally, this project is meant to test our knowledge with linear algebra and programming languages in ways we haven't done before.

2D Simulation

Equations
The first step to the 2D simulations is figuring out the path the black hole takes. To gather this information, we needed to use a few crucial equations:

Separation overtime \[ d(t) = \left[ d_0^4 - \frac{256}{5} \frac{G^3 m_1 m_2 M}{c^5} t \right]^{1/4} \] where \( d_0 \) is the initial separation at \( t = 0 \).

Orbital frequency overtime \[ \omega(t) = \sqrt{\frac{GM}{d(t)^3}} \] These equations can be written in Python as follows: 

def calculate_separation_over_time(self, time):
    inner_term = (self.initial_distance ** 4 - (256 / 5) *
        (
            (self.gravitational_constant ** 3
            * self.bh1_mass
            * self.bh2_mass
            * (self.bh1_mass + self.bh2_mass)
        ) / self.speed_of_light ** 5) * time
    )

    if inner_term <= 0:
        return 0.0

    return inner_term ** 0.25

def get_angular_frequency(self, separation):
    if separation <= 0:
        return 0.0
    return numpy.sqrt(
        (self.gravitational_constant * self.total_mass) / (separation**3)
        )

The separation overtime equation calculate the distance between two black holes at any given moment and the angular frequency equation tells us how quickly the black holes spin around each other for their current separation.

Extra data was generated as well, such as: waveform overtime, strain amplitude changes overtime, and the black hole's velocity difference between newtonian equations and relativistic equations. These equations are not relevant to the 2D simulation, but they can be found on our GitHub.

Rendering
Before rendering in 2D, inital conditions must be set for our black holes. Both black holes have a mass of 4e30 kilograms (roughly 2 solar masses) and starting positions of (50000, 50000), (-50000, -50000) kilometers. With these initial measurements, we can plug them into our equations to get position data. We used PyGame to draw circles onto the screen and plug that position data into the circle's position. This created the simulation you can see on the left.
