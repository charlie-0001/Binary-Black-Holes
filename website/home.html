Setup, planning, and goal

Setup
To setup the codebase and save version history, we created a github repository and periodically comitted our work there.

Planning
To plan, a project was created in github and issues would be added there to track progress and clearly show what needed to be worked on. Each issue would be split into the 5 default categories: backlog, ready, in progress, in review, and done.

What is the end goal?
The foremost goal of this project is to strengthen our knowledge and curiosity in physics while also using another skill we love, programming, to accomplish that. Additionally, this project is meant to test our knowledge with linear algebra and programming languages in ways we haven't done before.

2D Simulation

Equations
The first step to 2D simulation is figuring out the path the black hole takes. To gather this information, we needed to use one crucial equation: 

def calculate_separation_over_time(self, time):
    inner_term = (self.initial_distance ** 4 - (256 / 5) *
        (
            (self.gravitational_constant ** 3
            * self.bh1_mass
            * self.bh2_mass
            * (self.bh1_mass + self.bh2_mass)
        ) / self.speed_of_light ** 5) * time
    )

    if inner_term <= 0:
        return 0.0

    return inner_term ** 0.25
